# speedtest-cli

Консольный скрипт на Node.js для замера скорости скачивания к заданному URL.

## Требования

- Node.js >= 18 (используется `node:http`, `node:https`, `node:url`, `process.hrtime.bigint()`)
- Внешние зависимости не нужны

## Использование

```bash
node speedtest.js <URL>
```
## Пояснение

- Первый запрос тестовый для проверки соединения.
- Далее 10 запросов в URL 
- Замеряем в байтах и время до наносекунды

- Сжатие исключил. 
- Не получаем из кэша. 
- Таймаут 60 сек. 
- Последовательное выполнение запросов.
